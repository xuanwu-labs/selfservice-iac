**与 Terramate 主仓库的边界**：
- Terramate 既有目录（`cmd/`(terramate)、`commands/`、`engine/`、`hcl/`、`config/`、`stack/`、`generate/`、`cloud/`、`ls/`、`e2etests/`）**一律不修改**。
- CI 增加 lint 规则：禁止 `platform/**` 反向 import 被保护目录的非公开内部包；`make test` 与 `make build` 保持绿色，验证平台代码未侵入核心。
- 平台通过 `platform/internal/terramate` 的 exec 适配器调用 terramate 二进制，**不直接 import** terramate 内部包（保持 D1 解耦）。

## 2. 可插拔适配器接口（Go 伪代码）

```go
// platform/internal/adapters/git/git.go
type GitProvider interface {
    Clone(ctx, remote, into string) (Repo, error)
    Open(path string) (Repo, error)
}
type Repo interface {
    Fetch(ctx) error
    Checkout(ctx, ref string) error
    WorktreeAdd(ctx, path, branch string) (Worktree, error)
    Commit(ctx, msg string, paths ...string) (sha string, err error)
    Push(ctx) error
    HeadCommit() string
}

// platform/internal/adapters/state/state.go
type StateBackend interface {
    ListKeys(ctx, prefix string) ([]string, error)
    Lock(ctx, key string) (LockID, error)
    Unlock(ctx, key string, id LockID) error
}

// platform/internal/adapters/policy/policy.go
type PolicyEngine interface {
    // 对 plan JSON 做策略评估，返回 deny 规则
    Evaluate(ctx, planJSON []byte, input map[string]any) (Decision, error)
}

// platform/internal/adapters/cost/cost.go
type CostEstimator interface {
    Estimate(ctx, planJSON []byte) (CostReport, error)
}

// platform/internal/adapters/notify/notify.go
type Notifier interface {
    Notify(ctx, event Event) error
}

// platform/internal/terramate/terramate.go
type TerramateAdapter interface {
    Run(ctx, dir string, args ...string) (Result, error)   // exec terramate
    Generate(ctx, dir string) (Result, error)
}
```

每个接口有默认实现，可通过 `adapters_config`（DB）按 `kind` 切换实现。

## 4. `scripts/` 约定（对应 config 产物规整）

本 change 的脚本产出存放于 `openspec/changes/iac-self-service-platform/scripts/`，按**面向功能**分子目录：

```
scripts/
├── 初始化/          # 平台首次部署：DB 初始化、workspace 注册、默认适配器配置
├── 迁移/            # schema migration 脚本（配合 db/migrations）
├── 模块注册/        # 批量注册原子模块、契约提取辅助脚本
├── 编排执行/        # 触发流水线、对账、worktree 清理的工具脚本
└── 状态同步/        # state key 对账、漂移手动触发、同步策略执行辅助
```

- 脚本以功能聚合，命名中文，与 docs 形成对应。
- 实际脚本在 `apply` 阶段（`/opsx:apply`）随实现逐步产出；本 propose 阶段只确立约定。
