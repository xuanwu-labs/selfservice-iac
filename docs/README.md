# docs/

Aether 平台的 **用户文档**。

> 与 [`../openspec/`](../openspec/) 的区别:
> - `openspec/` = **设计过程文档**(规范驱动开发的 proposals/specs/design docs,面向开发者内部)
> - `docs/` = **用户文档**(面向使用 Aether 的最终用户与运维)

## 计划内容

| 文档 | 用途 |
|---|---|
| `getting-started.md` | 5 分钟快速上手 |
| `architecture.md` | 平台架构概览(精简版,完整设计见 openspec) |
| `cli-reference.md` | `aether` CLI 命令手册 |
| `api-reference.md` | API 参考(从 contracts/ 生成) |
| `operations.md` | 运维手册(部署、监控、故障排查) |

> **Status**: 平台尚处早期开发,文档待功能稳定后补充。

如需了解完整设计与架构决策,见 [`../openspec/`](../openspec/)。
